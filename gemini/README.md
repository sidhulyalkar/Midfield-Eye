# Gemini frontend handoff

Start with `docs/GEMINI_MASTER_PROMPT.md`. The files under `docs/` are authoritative; the copies in
this folder are convenience entrypoints and must not override the integrated delivery plan or
frontend blueprint.

The generated application must preserve the 100-player non-ranking policy and the gaze, body-mechanics, relational-control, evidence, and media-rights contracts.

After the base build, apply `V6_EMPIRICAL_PROMPT.md` to implement the Evidence Studio and Capture Studio.
