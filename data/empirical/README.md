# Empirical data layer

`open/` contains small, source-pinned excerpts whose upstream terms permit research use and public analysis with attribution. These excerpts are included to test parsers, provenance, and evidence-aware frontend behavior, not to replace the full datasets.

`templates/` contains schema examples only. Gated datasets such as Ego-Exo4D, WorldPose, SportsPose, AthletePose3D, SoccerNet GSR, and SoccerTrack v2 are never mirrored here. Use `midfielders-eye empirical-plan <source-id>` and complete the official license or registration process.

Every empirical view must expose the source, evidence tier, measured fields, inferred fields, confidence, and citation. Missing signals must remain missing.
